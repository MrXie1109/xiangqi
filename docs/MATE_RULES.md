## 已核对的原文

### 重炮（重迭炮）
> 指一方双炮在一条直线或横线上重叠相呼应，**一只炮当炮架，另一只炮将军，一举获胜**的杀法。
>
> —— [百度百科·重迭炮](https://wapbaike.baidu.com/item/%E9%87%8D%E8%BF%AD%E7%82%AE/14097368)

> **重炮杀**：用双炮重叠将军使对方棋子无法到将（帅）前应将的杀法称为"重炮"杀法。
>
> —— [百度百科·绝杀](https://wapbaike.baidu.com/item/%E7%BB%9D%E6%9D%80/405828)

### 闷宫
> 指**炮利用对方的士做炮架**将军，对方的将（帅）因己方士（仕）的阻碍无法脱离与炮在同一直线上，**作为炮架子的士也无法撤离**，从而将死对方。
>
> 闷宫的炮架子**一定是士**，而且要求将（帅）**紧贴炮架子**；如果炮架子不是士，或对方将（帅）已移动至肋线，则是闷杀。
>
> —— [百度百科·闷宫](https://wapbaike.baidu.com/item/%E9%97%B7%E5%AE%AB)

### 闷杀
> 将（帅）被叫将时因**被己方棋子阻挡**而无法逃往别处，或**被炮叫将时己方的炮架子因被阻挡而无法挪开**。
>
> 闷杀与闷宫的区别：闷宫的炮架是士，闷杀的炮架是士以外的其他子力。
>
> —— [百度百科·闷杀](https://wapbaike.baidu.com/item/%E9%97%B7%E6%9D%80/4555211)、[闷宫](https://wapbaike.baidu.com/item/%E9%97%B7%E5%AE%AB)

### 对面笑（白脸将）
> 一方用车或其它子力**利用双方将、帅不能在同一条直线上直接见面的规定**把对方将死的杀法。
>
> —— [百度百科·绝杀](https://wapbaike.baidu.com/item/%E7%BB%9D%E6%9D%80/405828)

### 双车错
> 利用**双车交替将军**而取胜的杀法。
>
> —— [百度百科·绝杀](https://wapbaike.baidu.com/item/%E7%BB%9D%E6%9D%80/405828)

### 卧槽马 / 挂角马 / 马后炮
> **卧槽马**：马在棋盘三·九（3·9）或七·九（7·9）位置上将军。
> **挂角马**：用马到九宫一角将军。
> **马后炮**：马与对方将（帅）在同一条直线或横线上，中间空一格，用炮在马后将军。
>
> —— [百度百科·绝杀](https://wapbaike.baidu.com/item/%E7%BB%9D%E6%9D%80/405828)

### 困毙
> 指轮到行棋的一方，棋子**没有被将军**，但所有棋子被困在原地无子可动，即被困毙。**被困毙的一方判负。**
>
> 困毙与绝杀不同：困毙是指被困一方**还没有被将军**，但所有棋子均无法移动；而绝杀则是一方主动将军，另一方无法解将而取胜。
>
> —— [百度百科·困毙](https://wapbaike.baidu.com/item/%E5%9B%B0%E6%AF%99)

### 铁门栓
> 出现在"绝杀"清单中：
> 对面笑、双车错、双车胁士、挂角马、八角马、卧槽马、钓鱼马、侧面虎、双马饮泉、马后炮、重炮、天地炮、闷宫、闷杀、双将、**铁门栓**、二鬼拍门、大刀穿心、三子归边、夹车炮、海底捞月、三车闹士、送佛归殿、小刀剜心法、车炮抽杀法、臣压君杀。
>
> —— [百度百科·绝杀](https://wapbaike.baidu.com/item/%E7%BB%9D%E6%9D%80/405828)

## 冲突与未决

**闷杀的定义存在两种用法**：

| 说法 | 原文 | 出处 |
|---|---|---|
| A：被将军时己方子堵路 | "将（帅）**被叫将时**因被己方棋子阻挡" | 百度百科·闷杀 |
| B：未被将军、无路可走 | 用户口述 | 未找到支持来源 |

而"困毙"的词条已经把"未被将军 + 无子可动"明确占用了：

> 棋子**没有被将军**，但所有棋子被困在原地无子可动，即被困毙。

也就是说 B 的描述就是困毙，不是闷杀。**采 A**。

沿用 A 之后，闷杀与闷宫的分界由闷宫词条给出：炮架是士 → 闷宫，炮架是士以外的子 → 闷杀。

但 A 仍与棋界口语习惯有出入（口语里常把"将军时被自己子堵死"直接叫闷杀/闷宫），
所以实现上：**闷杀只在"炮架不是士"时输出，其他情况回落绝杀，不硬套。**

# 补充：原先标"不做"的条目重新评估

之前把若干条标成"需历史/需过程"，这是判断错误。**杀法名描述的是终局盘面的形态**，
不需要回溯着法序列。逐条重估：

| 杀法 | 原文 | 终局可判要素 | 结论 |
|---|---|---|---|
| 天地炮 | "一炮镇中路，另一炮沉入对方底线，配合其它子力"[搏] | 炮1 在将所在列且隔架将军；炮2 在对方底线（黑方 y=0 / 红方 y=9）；有第三子形成杀 | ✅ 可判 |
| 双车胁士 | "双车侵入对方九宫两肋，弃车强行杀士"[搏2] | 双车分别占据两肋（x=3、x=5）；被将死 | ✅ 可判 |
| 大刀穿心 / 小刀剜心 | "车在其它子力配合下硬杀对方中心士"[搏3] | 走子**落点**是对方士位且为中线（将所在列）；配合将死 | ✅ 可判（用 last 落点） |
| 二鬼拍门 | "两兵(卒)占据咽喉线两肋道，强行破士"[搏] | 双兵分占 x=3、x=5 且深入九宫；被将死 | ✅ 可判 |
| 三车闹士 | "双车一兵或一车双兵或三兵强行攻破双士"[搏2] | 进攻方在九宫内同时有 ≥3 个车/兵；被将死 | ✅ 可判 |
| 铁门栓 | "用炮镇住中路的士象，再用车闷死将帅"[搏2] | 炮在中线（x=将列）且已破/牵制士象；车将军 | ✅ 可判 |
| 侧面虎 | "马与将相对位置状如双士连环，使将不能平移"[搏2] | 马在 (3,7)/(7,7)（高钓马位置）且控将门 | ✅ 可判 |
| 海底捞月 | "炮借将作炮架打掉守肋车后回车"[搏] | 需对方车已被吃掉，终局无可判特征 | ❌ 保留不实现 |
| 送佛归殿 | "兵步步将军，将逼回原位"[搏2] | 需着法序列 | ❌ 保留不实现 |
| 车炮抽杀 | "车抽将时塞住象眼成闷宫"[搏] | 需抽将过程 | ❌ 保留不实现 |
| 夹车炮 | "单车双炮配合，在对方2、3横线组成杀势"[搏3]；"双炮一车集于一侧，用重炮和车将死对方"[搏] | 车+双炮都在对方2、3横线一带（黑方 y≤2 / 红方 y≥7），且对将形成攻击 | ✅ 可判 |
| 三子归边 | "三个进攻子力集中一侧" | 布局态势 | ❌ 保留不实现 |
| 双马饮泉 | "马跳2、8线控制将门，另一马卧槽"[搏2] | 双马分居两侧，一马卧槽一马挂角，可判 | ⚠️ 与其它马杀重叠，暂缓 |

## 枚举的局限

两子组合无法构造出重炮（需两炮+炮架）、闷宫（需士）、臣压君（需己方子）等形态，
这几条用手工局面补充，且同样先验证 `legalMoves === 0` 才认。

## 实现顺序（= 优先级）

```
困毙 → 白脸将 → 双照将 → 重炮 → 闷宫 → 马后炮
     → 卧槽马 → 挂角马 → 八角马 → 钓鱼马 → 侧面虎
     → 双车错 → 臣压君 → 将死
```

理由：越具体的形制越靠前。重炮（双炮重叠）比闷宫（单炮隔士架）更具体，
所以截图那局判**重炮**而不是闷宫。
