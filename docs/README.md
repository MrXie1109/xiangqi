# 中国象棋 · 无服务器联机

单文件网页版中国象棋，电脑和手机打开同一页面即可对弈，不需要自建服务器。

打开页面 → 填同一个房间号 → 各选执红 / 执黑 → 开始。

## 玩法

- **本地双人**：一台设备轮流走，重开 / 悔棋 / 复制棋谱。
- **联机**：房间号即频道，数据经公共 MQTT 中继（`broker.emqx.io`）转发。
  联机时的认输、求和、悔棋都在按钮里，求和与悔棋需要对方同意。

## 特性

- 完整象棋规则：马腿、炮架、象不过河、士不出宫、将帅照面、困毙判负
- 三色棋子提示：绿=可白吃（无根），黄=假根（吃回仍吃亏），红=本方无根被打击
- 落子滑行动画、吃子碎散、将死杀法特效（对面笑 / 重炮 / 马后炮 / 双车错 / 铁门栓 / 闷杀 等）
- 断线重连自动追平：每次同步发完整棋谱，对方重放后对齐

## Android

`dist_xiangqi.apk` 是 WebView 壳，把 html/css/engine/mate/mqtt/app 六个文件打进 assets 离线运行，只申请联网权限。
安装后打开即用，界面与网页版完全一致。

## 部署

纯静态单文件，丢到任意静态托管即可。直接双击 `index.html` 用 `file://` 打开也能联机。

## 说明

公共 MQTT 中继匿名无鉴权，房间号是随机 8 位，知道房间号的人能看到这盘棋。

## 重新打包 APK

```bash
./tests/build-apk.sh
```

会重新拷贝 assets、生成 dex、对齐并签名，产物覆盖 `dist_xiangqi.apk`。
